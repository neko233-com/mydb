# MyDB v0.1.39

## 亮点

- **MySQL 9 Telemetry 三类 span 全量落地**：`Control`（启动/配置重载）、`session`（连接关闭）、`stmt`（所有语句）统一由 OTLP `/v1/traces` 导出。
- **查询属性 traceparent 透传**：服务端声明 `CLIENT_QUERY_ATTRIBUTES`，文本协议 `COM_QUERY` 与 prepared `COM_STMT_EXECUTE` 均解析具名属性；`stmt` 使用上游 `traceparent` 的 trace/parent span，缺少属性时自动回到 session 派生上下文。
- **OTLP 默认与 MySQL 9 一致**：`protocol: http/protobuf`、`compression: gzip`；手写 protobuf 编码覆盖 traces/metrics/logs，不再依赖 JSON。可用 `http/json` 回退调试。
- **MySQL 9 `mysql.*` 属性**：覆盖执行层可得的 `event_name`、`lock_time`、`digest_text`、`current_schema`、`errno/sqlstate/message_text`、rows、tmp tables、select/sort/no-index、cpu/memory 等字段。
- **连接热路径**：`TCP_NODELAY` 已开启；查询属性解析零额外分配，trace 仅在 OTLP traces 开启时记录，避免默认热路径开销。
- **OLAP**：保留页级 zone map 裁剪；范围/等值/IN/BETWEEN/IS NULL 谓词在解码前裁剪整页，并继续输出扫描/裁剪指标。
- **Linux musl**：发布仍为 `x86_64-unknown-linux-musl` 静态二进制，CI 校验无 `INTERP`/`NEEDED`。
