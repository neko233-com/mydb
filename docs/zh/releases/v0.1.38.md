# MyDB v0.1.38

## 亮点

- **OpenTelemetry 对齐 MySQL 9**：OTLP/HTTP 同时支持 metrics、traces、logs 三种信号；慢查询/错误语句导出为 `stmt` Internal span，附带 `mysql.digest_text`、`mysql.cpu_time`、`mysql.rows_sent`、`mysql.rows_affected`、`mysql.error_count` 等属性。
- **OTLP 日志**：新增 `/v1/logs`，`export_logs` 默认关闭；密码、token、secret、authorization、credential 字段强制脱敏。
- **OTLP 鉴权**：Basic（用户名+密码，支持密码文件/环境变量）与 Bearer；非 loopback 强制 HTTPS；管理状态接口不返回凭据。
- **OLAP 页级 zone map**：行存页按列记录 min/max/NULL，范围扫描保守裁剪；新增 `mydb_olap_pages_scanned/pruned/rows_pruned` 指标。
- **CDC 断点**：消费端 `checkpoint.json`、`checkpoint_lsn`、`lag_lsn`，支撑 TiDB 迁移追平与校验。
- **生产探针**：`/healthz`、`/readyz`、4 MiB 管理请求体上限；OTLP 配置启动校验。
- **Linux musl 静态发布**：`x86_64-unknown-linux-musl` 构建，校验无 `INTERP`/`NEEDED`，运行时不依赖 glibc。

## 已知边界

- 未实现 Session/Control span、`traceparent` 查询属性透传；当前 statement span 仅覆盖慢查询/错误语句。
- 未实现列裁剪、向量化聚合、并行页扫描。
- 本轮未重跑同机 MySQL 对比基准，不新增性能倍数结论。
- CDC 是 WAL 逻辑变更流，不是 MySQL binlog/GTID；跨库迁移需按 `docs/zh/tidb-migration.md` 的幂等 Loader 流程。
