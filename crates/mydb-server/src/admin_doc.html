MyDB 使用文档

MyDB 是 Rust 编写的单机数据库，提供 MySQL 8.4 协议连接、远程访问、Web SQL 工作台与管理 API。页面自动识别中英文，也可手动切换。

默认端口：MySQL 3306；Web 后台：4306。生产环境请使用强密码和 TLS。

快速开始客户端连接Web 后台SQL API远程连接认证与安全运维与排错

快速开始

Docker 开发配置可使用 root/root；原生新安装请使用安装器生成的 root 密钥文件。

mydb-server --config configs/default.yaml
mydb-cli -h <server-ip> -P 3306 -u root -p -D mydb

所有 JDBC、Go、Node.js、IDE 与远程客户端直接连接 3306，无需代理。

客户端连接

JDBC / DataGrip / IntelliJ

jdbc:mysql://<server-ip>:3306/mydb?useSSL=false&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true

使用 MySQL Connector/J 8.x/9.x，支持 caching_sha2_password 和 mysql_native_password。

Go database/sql

import _ "github.com/go-sql-driver/mysql"
db, err := sql.Open("mysql", "root:root@tcp(<server-ip>:3306)/mydb?parseTime=true")

Node.js / VS Code JavaScript / TypeScript

import mysql from "mysql2/promise";
const db = await mysql.createConnection({host:"<server-ip>",port:3306,user:"root",password:"root",database:"mydb"});

VS Code 数据库扩展、Notebook、迁移工具与任意 MySQL 驱动均可直连。

Web 后台与 SQL 工作台

打开 /admin 登录。支持 HTTP 管理账号和真实 MySQL 用户密码；SQL 按登录用户权限执行。

http://<server-ip>:4306/admin
http://<server-ip>:4306/admin/doc

页面自动识别浏览器语言；可选择 Auto、中文或 English 并保存。

SQL 管理 API

POST /api/v1/auth/login
{"username":"root","password":"root"}
POST /api/v1/sql/query
Authorization: Bearer <token>

API 返回结果集、列、行、影响行数和 last_insert_id，并复用权限、事务、WAL 与 MVCC 路径。

远程连接

默认 server.host 与 http.host 都是 0.0.0.0；在防火墙仅向内网放行 3306/4306，客户端把 host 改成服务器 IP。

jdbc:mysql://<server-ip>:3306/mydb?useSSL=false
mysql -h <server-ip> -P 3306 -u root -p

公网部署必须使用 TLS、强密码、最小权限、网络白名单和安全 secure_file_priv。

认证与安全

支持标准账户语法与常用 MySQL 认证插件：

CREATE USER 'app'@'%' IDENTIFIED BY 'strong-password';
GRANT SELECT ON mydb.* TO 'app'@'%';

密码只保存不可逆校验值。生产环境开启 require_secure_transport 并设置 TLS。

运维与排错

连接失败时确认 3306 监听、服务日志、账号插件、权限、TLS 参数和数据库名称。

危险管理操作需要显式确认：删除备份发送 X-MyDB-Confirm: DELETE_BACKUP:<backup-id>；恢复备份在 JSON 中发送 confirmation: "RESTORE_BACKUP:<backup-id>"。操作会写入审计日志。
